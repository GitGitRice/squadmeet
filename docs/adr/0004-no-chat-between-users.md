# No chat and no direct contact between users

Users meet strangers through the app, so they see only a Nickname and a predefined Avatar. There
is no chat, no free-text message and no uploaded profile photo. Ratings use predefined Reasons,
not free text. Reasons: free text between strangers needs moderation, reporting and harassment
handling that a 3-person team cannot deliver in 2 weeks, and it creates personal-data risk.
Contacts exist (both sides must accept, and users can Block), but they only drive Notifications
and invitations.
